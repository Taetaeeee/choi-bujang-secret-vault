# BYTE BACK 방어전 | 문제 해결 포트폴리오

> SKT ALEPH 교육과정의 BYTE BACK 방어전에서 수행한 작업을 **문제 → 해결 방법 → 검증**으로 정리한 기록입니다. 이 폴더는 실제 방어전 코드나 공식 심판 제출 자료를 대체하지 않습니다.

## 기록 원칙

- **기존 루트 `README.md`, `AGENTS.md`, 방어전 소스, 설정 파일은 수정하지 않습니다.** 이 폴더의 문서는 별도의 읽기용 기록입니다.
- 과거에 작성한 **3줄 기록 원문이 확인되면 그대로 보존**합니다. 원문을 확인할 수 없는 경우에는 루트 `README.md`의 기록으로 **새로 정리한 요약**이라고 표시하며, 당시 작성한 원문으로 가장하지 않습니다.
- 가상 Wazuh 경보 및 로컬 검증 결과와 실제 운영 ZTNA 연동·공식 심판 판정을 구분합니다. 미수행 검사나 확인되지 않은 성과를 성공 사례로 기록하지 않습니다.
- 비밀번호·토큰·개인키·서버 전용 키·실제 사용자 개인정보·가상 메모 본문을 이 폴더에 복사하지 않습니다.
- 코드·테스트 결과의 출처는 기존 저장소 파일 또는 해당 저장점 커밋으로 연결합니다.

## 문서 갱신 시 주의

`npm run bundle`은 작업 폴더가 깨끗한지 검사하고 **마지막 커밋에서 변경된 파일 목록**을 제출 묶음에 기록합니다. 방어전 제출에 필요한 커밋·검사·묶음 생성·심판 접수를 먼저 마무리한 후, 포트폴리오 문서만 별도 커밋하는 순서를 권장합니다. 문서 전용 커밋 후에도 배포 자동화가 작동할 수 있으므로 제출 중에는 커밋 시점을 주의합니다.
