# XDR-02 | 웹 주입 공격 탐지

**기록 출처:** 본 과제 대화에서 단계 완료 시 작성했던 포트폴리오용 3줄 기록 및 [기존 루트 README](../../../README.md)  
**저장점:** `e9a20ab` (2026-11-02)  
**문장 상태:** 아래 제작 1~5의 3줄은 이번 대화에서 실제 작성·검증했던 기록을 옮겼습니다.

## 과제 개요

가상 Wazuh 웹 접근 경보에서 SQL 주입, 스크립트 주입, 경로 이탈 등 공격 징후를 판별하고, 애매한 요청과 정상 이벤트를 구분했습니다. MITRE ATT&CK T1190을 근거로 사용했고 실제 웹 공격 차단 기능과는 구분해 로컬 거부 규칙을 검증했습니다.

## 제작 단계별 3줄 기록

### 제작 1 — 경보 읽기

- **문제:** 웹 접근 경보에 여러 정보가 섞여 있어 분석에 필요한 항목만 추출해야 했음.
- **해결 방법:** 시각·출발 IP·계정·규칙 수준·설명을 추출하는 독립적인 읽기 모듈을 구현함. 계정 정보가 없는 경보는 `null`로 처리함.
- **검증:** 가상 Wazuh 경보 26건에서 26줄을 출력하고, JavaScript 문법 검사를 통과함.

### 제작 2 — 패턴 목록

- **문제:** 웹 요청에 포함된 공격 징후와 정상적인 검색어를 구분할 기준이 필요했음.
- **해결 방법:** MITRE ATT&CK T1190을 근거로 SQL 주입, 스크립트 주입, 경로 이탈 패턴 3개를 정리함.
- **검증:** `patterns.json`에 패턴 3개와 각각 한 줄 근거가 작성됐음을 PowerShell로 확인함.

### 제작 3 — 판단 모듈

- **문제:** 웹 접근 경보에 SQL 주입·스크립트 주입·경로 이탈 공격과 정상 검색 요청이 혼재해 있었음.
- **해결 방법:** MITRE ATT&CK T1190 기반 패턴을 독립 판단 모듈에 적용하고, 공격 징후와 확신도에 따라 `block`, `alert`, `record`로 분류함.
- **검증:** 가상 경보 26건을 차단 8건, 경고 9건, 기록 9건으로 분류했으며 정상 이벤트 오차단 0건과 `import` 없는 독립 실행 구조를 확인함.

### 제작 4 — 알림과 차단

- **문제:** 웹 주입 공격을 탐지하더라도 차단 근거와 만료 조건이 없으면 정상 사용자까지 차단할 위험이 있었음.
- **해결 방법:** 명확한 공격에 대해서만 근거 경보 ID와 만료 시각이 있는 임시 거부 규칙을 생성하고, 경고를 별도 로그로 기록하도록 구현함.
- **검증:** 가상 경보 26건을 처리해 임시 거부 규칙 7개와 알림 로그 17줄을 생성하고, 로컬 검사에서 공격 `deny`, 정상·만료 `continue`를 확인함.

### 제작 5 — 시험 경보

- **문제:** 웹 주입 공격 판단 로직이 명확한 공격과 정상 요청을 올바르게 구분하는지 검증해야 했음.
- **해결 방법:** XDR 공식 실행기를 사용해 가상 Wazuh 경보 26건에 대한 분류 결과를 생성함.
- **검증:** 공식 실행기로 경보 26건을 처리해 `block` 8건, `alert` 9건, `record` 9건을 확인했으며 정상 이벤트 오차단은 0건이었음.

## 구현 한계

임시 거부 규칙은 `staged_only`입니다. 현재 ZTNA 판정기 요청 계약에 신뢰할 수 있는 출발지 IP가 없으므로 **운영 ZTNA 자동 차단은 구현·검증하지 않았습니다.** `continue`는 최종 접근 허용이 아닙니다. 실습용 Wazuh 경보에서의 성과를 실제 운영 보안 사고 대응 실적으로 표현하지 않습니다.
