# 2단계 | 공개 정적 자료 제거 및 서버 API 전환

**기록 출처:** [기존 루트 README — 2단계 저장점](../../../README.md)  
**문장 상태:** 당시 포트폴리오용 3줄 기록 원문을 확인하지 못해, README의 구현·점검 사실을 **새로 요약**했습니다.

## 과제 개요

공개 `data.json`에 있던 실습용 가상 메모를 최신 정적 배포에서 제외하고, 서버 API를 통해 Supabase의 실습용 자료를 조회하도록 변경했습니다.

## 3줄 요약 — 당시 원문 아님

- **문제:** 정적 배포 파일에 가상 메모 본문이 포함되어 공개적으로 열람될 수 있었습니다.
- **해결 방법:** 정적 `data.json` 경로를 제거하고, 브라우저가 `GET /api/notes`를 호출하며 Vercel 서버 함수가 Supabase 자료를 조회하는 구조로 변경했습니다. 서버 전용 키는 환경변수로 관리했습니다.
- **검증:** 기존 README의 2026-10-27 기록에서 배포 `/data.json` HTTP 404, 공개 `/api/notes`의 가상 메모 4건 응답, 최신 Git 파일의 정적 자료 제거 결과를 확인할 수 있습니다. 검사 당시 커밋과 이후 배포 재확인의 범위는 구분해야 합니다.

## 확인된 사실과 한계

- `api/notes.js`가 실습용 `vault_notes` 자료를 반환했고, 당시에는 로그인 없이 API 호출이 가능했습니다.
- 기존 공개 커밋과 이전 배포 이력에서 과거 가상 자료 노출까지 삭제된 것은 아닙니다.
- 위 검증은 **로그인·접근 통제를 완료했다는 의미가 아닙니다.** 이는 3~4단계에서 별도로 보완했습니다.
