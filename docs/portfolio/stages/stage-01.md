# 1단계 | BYTE BACK 초기 환경 구성 및 공개 배포

**기록 출처:** [기존 루트 README — 1단계 기록](../../../README.md)  
**문장 상태:** 당시 작성한 포트폴리오용 3줄 기록의 원문을 찾지 못했습니다. 아래 내용은 README에 남은 사실만으로 **나중에 새로 정리한 요약**입니다.

## 과제 개요

Public GitHub 저장소와 Vercel을 이용해 BYTE BACK 방어전 시작 틀을 배포하고, 방어전의 초기 상태를 확인하는 단계입니다. 초기에는 가상 메모 4건이 `/`와 `/data.json`에 노출된 상태였습니다.

## 3줄 요약 — 당시 원문 아님

- **문제:** 방어전 시작 틀의 공개 배포를 준비하고, 초기 가상 자료 노출 상태를 확인해야 했습니다.
- **해결 방법:** 본인 GitHub Public 저장소와 Vercel 배포를 연결하고, 방어전에서 요구한 배포 주소 제출 흐름을 따라 진행했습니다.
- **검증:** 루트 README에는 1단계 당시 `/` 및 `/data.json`에서 가상 메모가 보였다고 기록되어 있습니다. 1단계 공식 심판 판정 결과는 이 기록만으로 확인할 수 없습니다.

## 당시 상태와 한계

1단계는 자료 보호를 완료한 단계가 아닙니다. 당시 자료는 실습용 가상 메모였고, 이후 2단계에서 공개 정적 자료 제거 작업을 수행했습니다. 1단계 당시 작성한 정확한 3줄 기록을 확보하면 이 요약과 구분해 원문을 추가합니다.
