범용 프로필·지원조건 필터 수정본 (2026-10-27)

적용 순서
1. ZIP을 풀고 github-upload 안의 app/lib/tests/docs 폴더를 GitHub 저장소 루트에 업로드·커밋합니다.
2. Cloudflare 배포 완료 후 새로고침합니다. 키, D1 바인딩, 의존성 및 SQL 마이그레이션 변경 없음.
3. 내 프로필에서 최종학력, 희망 직무, 검색 키워드, 희망 지역, 해당 직무 경력(년)을 입력하고 저장합니다. 신입은 직무 경력에 0을 입력하세요. 빈칸을 경력 0년으로 추측하지 않습니다.
4. 공고 탐색 → 검증 대기에서도 학력·경력 등 필수조건 불일치가 기본 제외됩니다. 조건 일치/확인 필요/불일치 필터로 볼 수 있습니다. 불일치 결과를 보려면 프로필의 ‘필수조건 불일치 공고도 보기’를 켜고 저장합니다.

판정과 범위
- 고졸 프로필에 대졸/전문대졸 이상 필수 공고를 기본 제외. 대졸 우대 문구는 필수 학력으로 승격하지 않습니다.
- 필수 최소 경력 연수와 입력한 해당 직무 경력을 비교. 전체 근무 경력 문장을 임의로 직무 경력 연수로 변환하지 않습니다.
- 계약직·인턴·파견, 명시된 교대 조건을 공고의 확인 상태와 관계없이 비교합니다.
- 불명확한 학력·경력, 이미지 속 요건, 복수 모집분야, 자동 확인할 수 없는 필수 자격·업무능력은 확인 필요입니다. ‘조건 일치’는 확인한 조건에 충돌이 없다는 뜻이며 지원자격 전체 충족 또는 지원 가능 보장이 아닙니다.
- 조건 일치 → 확인 필요 → 불일치 순으로 정렬한 뒤 각 그룹 안에서 자격/기술 일치 개수를 비교합니다. 준비 중인 자격을 취득으로 보지 않습니다.
- 카드와 상세의 지원조건 비교에서 미충족·확인 필요 이유를 표시합니다.
- 희망 직무와 보유 기술을 분리했습니다. 직무+검색 키워드는 실제 조회와 관련성 필터에 사용하고 기술은 적합도 비교에 사용합니다. 명시한 직무와 키워드는 OR 검색어로 사용됩니다. 출처별 첫 키워드/요청 건수 제한은 유지됩니다.
- 사이드바 고정 직무 문구를 나의 검색 조건으로 바꾸고 저장한 희망 직무 또는 키워드를 표시합니다.
- ALIO의 고정 정보통신 NCS 필터를 제거했습니다. 지역·모집 중 조건의 제한된 목록에서 키워드를 비교하므로 전체 공고를 빠짐없이 수집하지는 않습니다. 고용24 등 기존 출처별 지원 지역·승인·상세 수집 제한은 유지됩니다.
- 새 회원에게는 대전/충청권·IT 키워드를 기본 적용하지 않습니다. 처음 프로필과 검색조건을 저장해야 수집합니다. 기존 회원이 저장한 값은 유지합니다.
- 자격·기술 자동완성에 회계/인사/사무/물류/설비 등 주요 예시를 추가했습니다. 공식 전체 자격 DB가 아니며 직접 입력 가능합니다.
- 세부지역 미확인 광역 공고 포함 옵션은 기본 꺼짐입니다. 켜면 선택한 세부지역이 속한 광역지역까지만 확인된 공고를 확인 필요 대상으로 볼 수 있습니다. 근무지 자체를 알 수 없는 공고는 계속 제외합니다.
- 검색 직무·키워드·지역 설정으로 수집 결과에 구분값을 저장합니다. 이전 조건 결과는 새 맞춤 목록에서 제외하고 원본 DB·관심·지원 기록은 보존합니다. 업데이트 이전 공고도 새 검색으로 다시 확인되기 전에는 새 결과에 섞지 않습니다. 프로필 저장 후 조회가 호출되지만 최소 1분 및 기존 출처 간격은 유지하므로 최근 호출이 있으면 다음 갱신이 필요할 수 있습니다.
- 기존 회원가입·개별 로그인·지역 삭제·자동완성·지원 메모·개별/순환 상세 수집을 보존합니다. 이 ZIP은 최신 회원/지역/프로필 패치 적용 프로젝트용 추가 업데이트입니다.

검증
타입 검사, 학력/경력/고용형태/교대/이미지/검색구분 단위 테스트, 기존 단위 테스트와 빌드. 로컬 Worker+D1에서 회원 데이터 분리·소유자 로그인·비밀값 비노출·지원 메모·이전 본문 보존 확인. 브라우저에서 고졸/경력0 입력 시 불일치 숨김, 불일치 보기 옵션과 판정 이유, 기존 본문/이미지/메모 흐름 확인. 실제 사용자 Cloudflare 배포는 업로드 후 이루어집니다.
