내 자료실

로그인 계정에 속한 실습용 가상 메모만 조회하고 관리합니다.

서버에서 로그인과 메모 소유자를 확인하고, 원본 메모 테이블의 직접 접근 권한은 회수했습니다. 실제 개인정보는 넣지 마세요.

BYTE BACK 접속 앱

브라우저 메뉴의 ‘앱 설치’ 또는 ‘홈 화면에 추가’로 사용할 수 있습니다. 별도의 접속 프로그램은 필요하지 않습니다.

기기 승인 상태: 서버 확인 전

앱 설치 여부나 로그인만으로 기기가 승인되지는 않습니다. 서버에서 승인 상태를 확인해야 보호 자료를 열 수 있습니다.

탈환 작전실 보기 (실제 확인·미실행 구분)

관리자에게 전달할 승인 요청 번호:

승인은 로그인과 별도입니다. 승인 요청은 대기 상태만 만들며, 실제 승인은 운영자가 확인합니다.

오프라인에서는 로그인·메모 조회·저장을 이용할 수 없습니다. 개인 자료를 오프라인에 저장하지 않습니다.

현재 오프라인으로 감지되었습니다. 인터넷에 다시 연결한 후 시도해 주세요.
