1~11단계 정상·금지 요청 실측 확인표

아래 표는 단계별 점검 절차입니다. 버튼으로 실행하는 5건은 읽기 전용 HTTP 요청이며, 메모 본문이나 로그인 정보는 기록하지 않습니다. 별도 운영 환경이 필요한 검사는 요청하지 않고 미실행으로 남깁니다.

아직 요청하지 않았습니다. 모든 결과는 미실행입니다.

단계유형점검 상황요청기대 결과실제 API 결과확인 상태요청 ID·출처확인 시각·출처

확인 방법: F12 → Network에서 해당 요청의 HTTP 상태와 X-Request-ID·X-Observed-At 응답 헤더를 비교하세요. 정적 파일 검사는 서버 헤더 대신 브라우저가 요청에 보낸 X-BB-Check-ID를 사용합니다. 응답 본문과 비밀값은 보관하지 않습니다.

41종 총공세: 이 버튼으로 실행하지 않습니다. 공식 41종 공격의 개별 실행·방어 결과는 이 표와 별도이며, 증거를 수집하기 전에는 통과로 표시하지 않습니다.
